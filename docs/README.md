# Quirewise documentation

Root keeps `README.md`, `LICENSE` and `CLAUDE.md` (Claude Code reads it only from the root; it points to `AGENTS.md`). Everything else is here.

`SETUP.md`: set up and run the project. `AGENTS.md`: engineering rules. `CHANGELOG.md`, `SECURITY.md`.

| Folder | Contents |
|---|---|
| `guides/` | `installation.md` (installer, MSI, portable, Explorer menu, signing), `components.md` (on-demand components) |
| `design/` | `architecture.md`, `threat-model.md`, `performance-budgets.md`, `ui-theme.md` |
| `adr/` | Architecture decision records, `0001` to `0012` |
| `tools/` | One page per tool, named by tool id |
| `legal/` | `PRIVACY.md`, `TERMS.md`, `THIRD_PARTY_NOTICES.md` |
| `project/` | `MASTER_PROMPT.md` (scope and phases), `HANDOFF.md` (session handoff), `open-questions.md` |
